# Лабораторная работа №2 — Список задач

Учебное приложение на чистых JavaScript, HTML и CSS. Вся структура интерфейса, метаданные и подключение CSS создаются через DOM API. HTML содержит только каркас и скрипт. Библиотеки и HTML-вставки не используются.

## Возможности

- Добавление задачи с обязательными названием и датой.
- Редактирование названия и даты, отмена кнопкой или Escape.
- Удаление и отметка выполнения.
- Поиск по названию без учёта регистра, фильтры по статусу и точной дате.
- Сортировка по возрастанию и убыванию даты.
- Ручной порядок: перетаскивание на верхнюю/нижнюю половину другой задачи либо стрелки.
- Ручной порядок доступен при отключённых фильтрах и поиске в режиме «Свой порядок».
- Автоматическое сохранение в localStorage и восстановление после перезагрузки.
- Адаптивная вёрстка, подписи полей, клавиатурное управление.

Сортировка по дате не меняет сохранённый ручной порядок. Задачи с одинаковыми датами сохраняют относительный порядок. Ошибка доступа к хранилищу выводится на странице; при повреждении данных приложение остаётся доступным.
